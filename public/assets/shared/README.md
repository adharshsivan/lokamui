# Shared Assets Directory

This folder holds assets shared across multiple game areas and locations.
**CRITICAL RULE:** Assets here must never be duplicated into specific location folders.

Subdirectories:
- `vegetation/`: Shared trees, palms, shrubs, flowers
- `props/`: Common furniture, trash bins, bollards, signs
- `benches/`: Park benches, stone seating
- `street/`: Streetlights, traffic signs, barriers
- `textures/`: Reusable PBR textures & normal maps
- `materials/`: Shared material definitions and atlases
- `animations/`: Reusable humanoid locomotion & interaction clips
- `audio/`: Ambient loops, UI sounds, surface footsteps
- `icons/`: UI icons and minimap markers
