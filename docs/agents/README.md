# Agent Handoff Directory

This directory contains modular handoff notes written by AI sessions upon completing work in a specific subsystem.

## Rules:
1. **Do not create one giant progress file.**
2. When completing work on a system, update or create `docs/agents/<system-name>.md` (e.g. `player-system.md`, `vehicle-system.md`, `kochi-island.md`).
3. Future AI sessions should inspect the relevant file before touching that subsystem.
